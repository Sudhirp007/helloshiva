## 3. Non-Negotiable Operational Guardrails

All autonomous agents and developers working on this repository must strictly adhere to these rules:

1. **State Preservation First:**  
   The production SQLite database at `/var/www/helloshiva/data/` contains live enquiries and CRM state. It must **NEVER** be overwritten during code releases. Pre-deploy backups are mandatory.
2. **Editorial Quality Standard (No Autonomous AI Spam):**  
   Autonomous publishing of unverified AI articles is strictly forbidden. The Content Intelligence engine acts as an accelerator for human experts. Every published article must contain unique client insights, structured semantic headings (H1 $\rightarrow$ H2 $\rightarrow$ H3), and human editorial sign-off.
3. **Zero 404 Tolerance:**  
   Any legacy URL that received historical impressions in Search Console must be permanently 308/301 redirected to an active, relevant destination.
4. **Mobile Performance Guarantee:**  
   Because 60% of visitors browse on mobile smartphones (Android/Chrome), mobile Largest Contentful Paint (LCP) must remain under 1.2s and Cumulative Layout Shift (CLS) at 0.
5. **No Hardcoded Credentials:**  
   API keys, private keys, and service account tokens must strictly reside in `.secrets/` (git-ignored) or environment variables.

## 5. Architecture Evolution Thresholds

Do not over-engineer early. Migrate infrastructure only when real telemetry triggers these thresholds:

* **Database Migration (SQLite $\rightarrow$ Managed PostgreSQL):** Trigger when daily active sessions exceed 5,000 or concurrent write lock conflicts occur in journalctl.
* **Redirect Offloading (Node.js $\rightarrow$ Cloudflare Edge):** Trigger when permanent redirect rules exceed 50 entries in `next.config.mjs`.
* **CI/CD Pipeline Migration (Tar/SCP $\rightarrow$ Containerized GitHub Actions):** Trigger when engineering team expands beyond 1 developer or deployment bundle exceeds 100MB.
